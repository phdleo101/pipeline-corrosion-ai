# 腐蚀失效案例库（Corrosion Failure Case Library）

> 本案例库整理自公开文献与工程报道的典型腐蚀失效模式，用于教学、风险识别与方案比选参考。
> 案例数据为脱敏后的典型量级，具体工程请以现场检测与标准评估为准。

---

## 1. 长输管道 CO₂ 内部腐蚀穿孔

- **行业**：油气长输
- **失效模式**：CO₂ 均匀腐蚀 + 局部冲刷腐蚀
- **工况**：碳钢集输管道，温度 65°C，CO₂ 分压 1.2 MPa，pH 5.8，段塞流
- **机理**：CO₂ 溶于水形成碳酸，与 Fe 反应生成 FeCO₃。低温下保护膜不完整，局部冲刷破坏膜层导致穿孔。
- **后果**：投产 3 年发生穿孔泄漏，单处抢修停产 5 天，直接损失超百万元。
- **启示**：高 CO₂ 分压环境应优先选用耐蚀合金（13Cr/双相钢）或连续加注成膜胺缓蚀剂；在段塞流、积液段加密内检测（ILI）。

## 2. 海底管道微生物腐蚀（MIC）

- **行业**：海洋油气
- **失效模式**：SRB 驱动的微生物腐蚀坑点
- **工况**：海底碳钢管线，海床沉积物覆盖，温度 30°C，溶解氧 < 0.5 mg/L，检测 SRB 10⁵ MPN/mL
- **机理**：硫酸盐还原菌在沉积物-金属界面形成生物膜与浓差电池，局部厌氧环境加速坑点腐蚀。
- **后果**：管壁点蚀深度超过壁厚 60%，剩余强度不足被迫更换管段。
- **启示**：关注低流速、死水区与沉积物堆积；定期投加非氧化性杀菌剂；对坑点缺陷按 ASME B31G 评估剩余强度。

## 3. 316 不锈钢换热器氯离子应力腐蚀开裂（SCC）

- **行业**：化工 / 电力
- **失效模式**：氯离子应力腐蚀开裂
- **工况**：316 不锈钢换热器管束，介质含 Cl⁻ 8000 ppm，温度 90°C，存在焊接残余应力
- **机理**：Cl⁻ 在拉应力与敏感温度下沿晶界引发 SCC，裂纹快速扩展至贯穿泄漏。
- **后果**：运行中突发泄漏，装置非计划停机。
- **启示**：高 Cl⁻ + 高温环境应避免常规奥氏体不锈钢；升级为双相钢 2205（PREN≈34）或镍基合金；消除焊接残余应力（固溶/退火）。

## 4. 埋地管道外部土壤腐蚀

- **行业**：城市燃气管网
- **失效模式**：外部腐蚀（土壤）+ 阴极保护失效
- **工况**：埋地钢管，土壤电阻率 800 Ω·cm，pH 4.8（酸性），含水率 28%，防腐层老化剥离
- **机理**：低电阻率酸性土壤 + 防腐层破损处形成腐蚀电池，阴极保护电位不足时外腐蚀快速发展。
- **后果**：防腐层下集中腐蚀导致管体减薄破裂，燃气泄漏引发安全事故。
- **启示**：埋地管道应采用 3PE/FBE 外防腐层 + 强制电流阴极保护；定期测量保护电位（≤ -0.85 V vs CSE）；重视绝缘接头与排流。

## 5. 铜合金-碳钢电偶腐蚀

- **行业**：船舶 / 海水冷却系统
- **失效模式**：电偶腐蚀
- **工况**：铜合金冷凝器与碳钢管路直接连接，海水介质，阴极（铜）面积远大于阳极（碳钢）
- **机理**：铜-铁电位差驱动碳钢作为阳极加速溶解，大阴极小阳极效应使碳钢端快速腐蚀穿孔。
- **后果**：碳钢管路连接段短期内腐蚀减薄泄漏。
- **启示**：异种金属连接必须采用绝缘法兰/垫片隔离；或使阳极面积大于阴极面积；必要时加牺牲阳极（锌/镁）。

## 6. 常压储罐底板腐蚀

- **行业**：石油储运
- **失效模式**：底板下部土壤侧腐蚀 + 边缘板腐蚀
- **工况**：原油储罐，底板下方回填土含水率高，边缘板与基础环梁处存在缝隙与积水
- **机理**：底板与基础间形成氧浓差电池，边缘板受力变形产生缝隙，积水加速局部腐蚀。
- **后果**：底板穿孔导致油品渗漏，地基污染。
- **启示**：底板采用涂层 + 阴极保护（网状阳极）；边缘板加防水密封；定期漏磁检测（MFL）。

## 7. 高温硫化物腐蚀（加氢装置）

- **行业**：炼油
- **失效模式**：高温硫腐蚀
- **工况**：加氢反应器出口管线，温度 320°C，含 H₂S + H₂，碳钢/低合金钢
- **机理**：高温下 H₂S 与 Fe 反应生成 FeS 并有 H₂ 扩散（氢损伤），壁厚均匀减薄 + 氢致开裂风险。
- **后果**：管线均匀减薄接近最小壁厚，需提前更换。
- **启示**：高温硫环境应按 NACE MR0175 / API 571 选用 1.25Cr-0.5Mo 或 5Cr 以上合金钢；控制原料硫含量并监测壁厚。

## 检索速查

| 失效模式 | 典型材料 | 关键诱因 | 推荐对策 |
|---------|---------|---------|---------|
| CO₂ 内部腐蚀 | 碳钢 | 高 CO₂ 分压、低 pH、段塞流 | 耐蚀合金 / 缓蚀剂 / ILI |
| MIC 微生物腐蚀 | 碳钢 | SRB、沉积物、低流速 | 杀菌剂 / 清管 / B31G 评估 |
| 氯离子 SCC | 奥氏体不锈钢 | 高 Cl⁻ + 高温 + 应力 | 双相钢/镍基 / 消除应力 |
| 土壤外腐蚀 | 埋地钢管 | 低电阻率、酸土、阴保失效 | 3PE+强制电流阴保 / 电位监测 |
| 电偶腐蚀 | 异种金属连接 | 电位差、大阴极小阳极 | 绝缘隔离 / 牺牲阳极 |
| 储罐底板腐蚀 | 碳钢底板 | 缝隙、积水、氧浓差 | 涂层+网状阳极 / MFL 检测 |
| 高温硫腐蚀 | 碳钢/低合金 | 高温 H₂S+H₂ | Cr-Mo 合金 / 壁厚监测 |
