# 中国管道腐蚀防护标准知识库

本知识库汇总中国管道腐蚀与完整性管理领域的主要国家标准和行业标准，补充国际标准（NACE/API/ASME）的国内对应内容，用于支撑智能问答系统。

---

## 1. GB/T 23258 — 埋地钢质管道外防腐层技术标准

### 适用范围
埋地钢质管道外防腐层的设计、选材、施工、检验和验收。

### 防腐层等级
| 等级 | 结构 | 适用土壤 | 设计寿命 |
|------|------|----------|----------|
| 加强级 | 三层PE / 熔结环氧 | 强腐蚀土壤 | 30-50年 |
| 普通级 | 二层PE / 环氧煤沥青 | 中等腐蚀土壤 | 20-30年 |
| 弱级 | 沥青涂层 / 聚乙烯胶粘带 | 弱腐蚀土壤 | 10-20年 |

### 防腐层选择原则
- 土壤电阻率 < 50 Ω·m：必须采用加强级防腐
- 土壤电阻率 50-100 Ω·m：采用普通级防腐
- 土壤电阻率 > 100 Ω·m：可采用弱级防腐
- 穿越河流、铁路等关键段：一律采用加强级防腐
- 与阴极保护配合使用时，防腐层电阻应 > 10⁴ Ω·m²

### 防腐层补口要求
- 补口材料应与主管防腐层兼容
- 补口前管表面处理应达到 Sa2.5 级（近白级喷砂）
- 补口区防腐层厚度不低于主管防腐层厚度
- 补口后进行电火花检漏，检漏电压按 GB/T 23258 规定

## 2. SY/T 0087 — 钢质管道及储罐腐蚀评价方法

### 腐蚀评价流程
1. **现场调查**：环境条件、操作参数、历史数据收集
2. **检测实施**：内检测(ILI)/外检测(ECDA)/开挖验证
3. **数据分析**：腐蚀缺陷识别、尺寸量化、增长速率估算
4. **风险评价**：失效概率 + 失效后果 → 风险等级
5. **完整性评估**：剩余强度计算、剩余寿命预测
6. **维修决策**：立即维修/计划维修/持续监测

### 腐蚀速率确定方法
| 方法 | 适用场景 | 精度 |
|------|----------|------|
| 壁厚测量对比法 | 有历史壁厚数据 | 中（需至少2次测量） |
| 内检测数据对比法 | 有多次ILI数据 | 高（可计算局部增长速率） |
| 挂片法 | 新管道或无历史数据 | 中（需1-12个月暴露） |
| 在线探针法 | 实时监测 | 高（可连续记录） |
| 模型计算法 | 设计阶段预估 | 低（需实际数据校验） |

### 腐蚀评价等级
| 评价等级 | 腐蚀程度 | 壁厚损失 | 处理建议 |
|----------|----------|----------|----------|
| A级 | 轻微 | < 10% 公称壁厚 | 正常运行，常规监测 |
| B级 | 中等 | 10%-20% | 加强监测，记录跟踪 |
| C级 | 较重 | 20%-40% | 评估剩余强度，制定维修计划 |
| D级 | 严重 | > 40% 或接近最小允许壁厚 | 立即维修或更换 |

## 3. GB 50251 — 输气管道工程设计规范

### 腐蚀控制要求
- 输气管道必须设置外防腐层 + 阴极保护双重防腐系统
- 阴极保护应在管道埋地后1年内投入运行
- 通电点电位应控制在 -0.85V ~ -1.20V（相对Cu/CuSO₄电极）
- 管道沿线每隔1-2km设置测试桩
- 高后果区管道应安装在线腐蚀监测系统

### 材料选择
| 介质条件 | 推荐管材 | 标准依据 |
|----------|----------|----------|
| 干燥天然气 | 碳钢 + 防腐层 | GB/T 9711 |
| 含CO₂天然气 | 13Cr / 316不锈钢 / 缓蚀剂 | NACE MR0175 + GB 50251 |
| 含H₂S天然气 | 抗硫碳钢 / 双相不锈钢 | NACE MR0175 / ISO 15156 |
| 高CO₂+高Cl⁻ | 2507双相 / 625合金 | NACE MR0175 + 工程评估 |

### 管道设计寿命
- 干线管道：设计寿命不少于30年
- 集输管道：设计寿命不少于20年
- 防腐层设计寿命：与管道设计寿命一致
- 阴极保护系统设计寿命：不少于25年

## 4. SY/T 6648 — 油气管道完整性管理规范

### 完整性管理循环
```
数据采集 → 风险评价 → 完整性评估 → 维修与风险降低 → 效能评价 → （循环）
```

### 风险评价方法
- **定性方法**：风险矩阵法（概率×后果）
- **半定量方法**：指数评分法（多因素加权）
- **定量方法**：QRA定量风险评估（计算失效概率和后果）

### 高后果区识别
| 类别 | 描述 | 管理要求 |
|------|------|----------|
| 一级 | 人口密集区（>100户） | 优先评估，周期≤5年 |
| 二级 | 环境敏感区（水源/生态） | 重点监测，周期≤7年 |
| 三级 | 工业区/交通干线 | 常规管理，周期≤10年 |

### 完整性评估方法选择
| 管道类型 | 推荐方法 | 备选方法 |
|----------|----------|----------|
| 可清管管道 | 内检测(ILI) | 压力试验 |
| 不可清管管道 | 直接评估(ECDA/ICDA) | 压力试验 |
| 新建管道 | 基线评估(ILI+ECDA) | 压力试验 |
| 高后果区管道 | ILI + ECDA联合 | 压力试验 |

## 5. GB/T 21447 — 钢质管道外腐蚀控制规范

### 阴极保护准则
- **通电电位法**：管道通电点电位 ≤ -0.85V（相对Cu/CuSO₄电极）
- **断电电位法**：瞬时断电电位 ≤ -0.85V（消除IR降影响）
- **100mV极化准则**：极化衰减不小于100mV
- **最负电位限制**：≤ -1.20V（避免过保护导致涂层剥离和氢脆）
- 特殊环境（高温/高电阻率土壤）可适当调整准则

### 阴极保护系统设计
- 保护电流密度根据防腐层质量和土壤条件确定
- 三层PE防腐层：0.01-0.05 mA/m²
- 环氧粉末防腐层：0.05-0.10 mA/m²
- 沥青防腐层：0.10-0.50 mA/m²
- 裸管：5-50 mA/m²

### 阳极地床设计
| 阳极类型 | 适用场景 | 设计寿命 | 消耗率 |
|----------|----------|----------|--------|
| 高硅铸铁 | 淡水/土壤 | 20-30年 | 0.1-0.5 kg/A·a |
| 钛基贵金属氧化物 | 海水/高盐土壤 | 30-50年 | < 0.01 kg/A·a |
| 柔性阳极 | 高电阻率土壤/复杂管网 | 20-30年 | — |
| 镁合金牺牲阳极 | 短管道/低电阻率土壤 | 10-15年 | 7-8 kg/A·a |

## 6. GB/T 30582 — 基于风险的埋地钢质管道完整性评价

### 风险评价模型
- 失效概率 = 腐蚀概率 × 第三方破坏概率 × 设备失效概率 × 自然灾害概率
- 失效后果 = 人员伤亡 + 财产损失 + 环境影响 + 社会影响
- 风险值 = 失效概率 × 失效后果

### 风险矩阵
|  | 后果-低 | 后果-中 | 后果-高 | 后果-极高 |
|--|---------|---------|---------|-----------|
| **概率-高** | 中风险 | 高风险 | 极高风险 | 极高风险 |
| **概率-中** | 低风险 | 中风险 | 高风险 | 极高风险 |
| **概率-低** | 低风险 | 低风险 | 中风险 | 高风险 |
| **概率-极低** | 低风险 | 低风险 | 低风险 | 中风险 |

### 风险降低措施
- **降压运行**：降低操作压力至安全水平
- **缺陷修复**：焊接修复/复合材料修复/更换管段
- **增加监测**：加密内检测/安装在线监测系统
- **缓蚀剂优化**：调整缓蚀剂类型和注入方案
- **阴保优化**：调整保护参数/增设阳极地床

## 7. SY/T 0036 — 埋地钢质管道强制电流阴极保护设计规范

### 设计要点
- 保护范围：全线连续保护，无保护盲区
- 阳极地床选址：土壤电阻率 < 100 Ω·m，距管道100-500m
- 电源设备：恒电位仪或恒电流仪，输出功率留有50%余量
- 绝缘接头：在管道进出口设置绝缘接头，防止电流流失
- 测试系统：每隔1-3km设置测试桩，关键位置安装远程监测探头

### 与国际标准对应关系
| 中国标准 | 对应国际标准 | 主要差异 |
|----------|-------------|----------|
| GB/T 21447 | NACE SP0169 | 保护电位准则基本一致 |
| SY/T 0036 | NACE TM0497 | 测试方法类似 |
| GB/T 23258 | NACE SP0185 | 涂层分类体系略有不同 |
| SY/T 0087 | API 570 | 评价方法基本一致 |
| SY/T 6648 | API 1160 | 管理框架一致，细节有差异 |
| GB 50251 | ASME B31.8 | 设计要求类似 |

## 8. 国内管道腐蚀管理法规要求

### 安全监管
- 《石油天然气管道保护法》（2010年施行）：管道企业应定期进行管道完整性检测
- 《特种设备安全法》：压力管道属于特种设备，需定期检验
- 《管道完整性管理规范》：高风险管道每年至少1次风险评估

### 检验周期要求
| 管道类别 | 检验类型 | 法定周期 | 备注 |
|----------|----------|----------|------|
| GA类(长输) | 全面检验 | ≤8年 | 高后果区≤5年 |
| GA类(长输) | 年度检查 | ≤1年 | 运行单位自检 |
| GB类(公用) | 全面检验 | ≤6年 | 高风险段≤4年 |
| GC类(工业) | 全面检验 | ≤3-6年 | 按介质危险性分 |

### 应急管理
- 管道企业应制定管道事故应急预案
- 高后果区管道应每3年至少演练1次
- 建立管道泄漏检测系统(LDS)，报警响应时间<5分钟
- 配备应急抢修队伍和物资储备
