## 1. GB/T 23258《埋地钢质管道外防腐层技术标准》

### 1.1 防腐层厚度要求（最小平均值 / 最小单个值）
| 防腐层类型 | 适用管径 | 最小平均厚度 (mm) | 最小单个值 (mm) |
|------------|----------|-------------------|-----------------|
| 熔结环氧 FBE（一层） | 所有 | 0.38（DN≤100）/ 0.40（DN>100） | 0.30 |
| 三层 PE（普通级） | ≤DN400 | 1.8 | 1.5 |
| 三层 PE（加强级） | >DN400 | 2.5 / 3.0（≥DN800） | 2.2 / 2.7 |
| 环氧煤沥青（普通级） | — | ≥0.3（普通级） | — |
| 聚乙烯胶粘带 | — | ≥0.7（内带+外带） | — |

### 1.2 补口与检漏
- 补口前钢管表面处理等级：**Sa2.5 级**（GB/T 8923 近白级喷砂）。
- 电火花检漏电压（FBE）：**5 kV 及以上，按 5 kV/mm 递增**（或按厂家规定）。
- 三层 PE 补口检漏电压：依据涂层厚度，通常 **15–25 kV**。
- 耐阴极剥离（65°C, 48h）：剥离距离 **≤8 mm**（行业标准常见验收指标）。

### 1.3 等级选用（与土壤电阻率挂钩）
- ρ < 50 Ω·m → 加强级；50 ≤ ρ ≤ 100 → 普通级；ρ > 100 → 弱级；穿越段一律加强级。

## 2. SY/T 0087《钢质管道及储罐腐蚀评价方法》

### 2.1 腐蚀评价等级（壁厚损失占比）
| 等级 | 壁厚损失 | 处理建议 |
|------|----------|----------|
| A | < 10% | 正常运行，常规监测 |
| B | 10%–20% | 加强监测、记录跟踪 |
| C | 20%–40% | 评估剩余强度、制定维修计划 |
| D | > 40% 或接近 t_min | 立即维修或更换 |

### 2.2 剩余寿命估算（线性外推）
```
剩余寿命(年) = (当前剩余壁厚 − 最小允许壁厚) / 年平均腐蚀速率
最小允许壁厚 t_min 按 GB/T 9711 / 设计规范确定（通常含腐蚀裕量）
```
- 腐蚀速率确定优先顺序：多次 ILI 对比 > 壁厚测量对比 > 在线探针 > 挂片 > 模型预估。
- 评价结论须给出**置信度**：A 级（高，有实测）、C 级（中，部分推算）、D 级（低，仅模型）。

### 2.3 维修决策阈值
- 金属损失深度 ≥ 80% t 公称 → 立即修复（与 ASME B31G 危险缺陷一致）。
- 裂纹/开裂类缺陷 → 不允许存在，立即评价与修复。

## 3. GB 50251《输气管道工程设计规范》

### 3.1 设计系数与壁厚
- 地区等级一级（人口稠密）→ 设计系数 0.72；二级 0.6；三级 0.5；四级 0.4。
- 直管段最小壁厚计算按 GB/T 9711 + 设计压力，并计入**腐蚀裕量**（一般 1–3 mm）。

### 3.2 阴极保护要求
- 埋地后 **1 年内**投运阴极保护。
- 通电点电位：**−0.85 V ~ −1.20 V**（相对 Cu/CuSO₄ 参比电极）。
- 高后果区应设在线腐蚀监测。
- 管道沿线测试桩间距 **1–2 km**。

### 3.3 材料选用（含腐蚀介质）
| 介质条件 | 推荐管材 | 依据 |
|----------|----------|------|
| 含 CO₂ | 13Cr / 316 / 缓蚀剂 | NACE MR0175 + 本规范 |
| 含 H₂S | 抗硫碳钢 / 双相钢 | NACE MR0175 / ISO 15156 |
| 高 CO₂ + 高 Cl⁻ | 2507 / 625 | 工程评估 |

### 3.4 设计寿命
- 干线 ≥ 30 年；集输 ≥ 20 年；CP 系统 ≥ 25 年。

## 4. SY/T 6648《油气管道完整性管理规范》

### 4.1 完整性管理六步循环
```
数据采集 → 高后果区识别 → 风险评价 → 完整性评价 → 维修与风险降低 → 效能评价 →（循环）
```

### 4.2 高后果区（HCA）识别与再评价周期
| 类别 | 描述 | 再评价周期 |
|------|------|------------|
| 一级 | 人口密集区（>100 户） | ≤ 5 年 |
| 二级 | 环境敏感区（水源/生态） | ≤ 7 年 |
| 三级 | 工业/交通干线 | ≤ 10 年 |

### 4.3 评价方法选择
- 可清管 → ILI（优先）；不可清管 → ECDA/ICDA；高后果区 → ILI + ECDA 联合。

### 4.4 风险评价方法
- 定性：风险矩阵（概率×后果）；半定量：指数评分；定量：QRA。

## 5. GB/T 21447《钢质管道外腐蚀控制规范》

### 5.1 阴极保护准则（四条可选）
1. 通电电位 ≤ **−0.85 V**（Cu/CuSO₄）。
2. 断电（瞬时）电位 ≤ **−0.85 V**（消除 IR 降）。
3. **100 mV 极化衰减**准则（适用于微生物/硫酸盐环境）。
4. 最负限制 ≤ **−1.20 V**（防过保护导致涂层剥离/氢脆）。

### 5.2 保护电流密度（按防腐层）
| 防腐层 | 保护电流密度 (mA/m²) |
|--------|----------------------|
| 三层 PE | 0.01–0.05 |
| FBE | 0.05–0.10 |
| 沥青 | 0.10–0.50 |
| 裸管 | 5–50 |

### 5.3 阳极地床
- 高硅铸铁：淡水/土壤，20–30 年，消耗 0.1–0.5 kg/A·a。
- 钛基 MMO：海水/高盐，< 0.01 kg/A·a。
- 镁牺牲阳极：短管/低电阻率，7–8 kg/A·a。

## 6. GB/T 30582《基于风险的埋地钢质管道完整性评价》

### 6.1 风险量化模型
```
风险值 = 失效概率 × 失效后果
失效概率 = f(腐蚀, 第三方破坏, 设备失效, 自然灾害)
失效后果 = 人员伤亡 + 财产损失 + 环境影响 + 社会影响
```

### 6.2 风险矩阵（5×5，概率×后果）
- 极低/低/中/高/极高 五级。
- 高风险及以上 → 立即风险降低（降压、修复、加密监测）。

### 6.3 风险降低措施优先级
1. 缺陷修复（复合材料/焊接/换管）；2. 降压运行；3. 增加监测（ILI/在线）；4. 缓蚀剂/阴保优化。

## 7. SY/T 0036《埋地钢质管道强制电流阴极保护设计规范》

### 7.1 设计要点
- 全线连续保护，无盲区。
- 阳极地床：土壤电阻率 < 100 Ω·m，距管道 100–500 m。
- 电源：恒电位仪，输出功率留 **50% 余量**。
- 绝缘接头：进出端设置，防电流流失。
- 测试桩：1–3 km 一处，关键位设远程监测探头。

### 7.2 与国际对应
- SY/T 0036 ↔ NACE TM0497（测试）；
- GB/T 21447 ↔ NACE SP0169（准则）；
- SY/T 0087 ↔ API 570（评价）。

## 8. 法定检验与应急（监管条款归纳）
- 《石油天然气管道保护法》：定期完整性检测。
- GA 类长输：全面检验 ≤ 8 年（高后果区 ≤ 5 年），年度检查 ≤ 1 年。
- GB 类公用：全面检验 ≤ 6 年（高风险段 ≤ 4 年）。
- 高后果区应急预案演练：每 **3 年**至少 1 次；泄漏检测系统报警响应 < **5 分钟**。
