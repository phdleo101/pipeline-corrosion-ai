# Dify RAG 智能问答配置指南

本指南将帮助你配置 Dify Cloud API，让管道腐蚀 AI 系统的标准问答模块从"基础模式"升级到"智能问答模式"。

---

## 前置准备

- 已注册 Dify 账号（https://cloud.dify.ai）
- 知识库文档已准备好（`data/standards/corrosion_standards_kb.md`）

---

## 第 1 步：注册 Dify 账号

1. 打开 https://cloud.dify.ai
2. 点击 **注册**，使用邮箱或 Google/GitHub 账号注册
3. 登录后进入 Dify 控制台

> Dify 免费版提供 200 次 GPT 调用额度，足够测试使用。

---

## 第 2 步：创建知识库

1. 在左侧导航栏点击 **「知识库」**
2. 点击 **「创建知识库」**
3. 上传文件：
   - 点击 **「导入文件」**
   - 选择 `data/standards/corrosion_standards_kb.md` 文件上传
   - 等待文件处理完成（文本提取 + 分段）

4. 分段设置：
   - **分段方式**：选择「自动分段」
   - **分段长度**：500 字符
   - **分段重叠**：50 字符
   - 点击 **「保存并处理」**

5. 嵌入模型设置：
   - **嵌入模型**：选择 `text-embedding-3-small`（OpenAI，免费版可用）
   - 或选择其他可用模型
   - 点击 **「保存并处理」**

6. 等待知识库处理完成（状态变为「可用」）

---

## 第 3 步：创建聊天助手应用

1. 在左侧导航栏点击 **「工作室」**
2. 点击 **「创建空白应用」**
3. 选择应用类型：**「聊天助手」**
4. 填写应用信息：
   - **应用名称**：管道腐蚀标准问答
   - **应用描述**：基于 NACE/API/ASME 标准的管道腐蚀知识问答
5. 点击 **「创建」**

---

## 第 4 步：关联知识库

1. 在应用编排页面，找到 **「上下文」** 设置
2. 点击 **「添加」** 按钮
3. 选择刚才创建的「管道腐蚀标准知识库」
4. 设置参数：
   - **Top K**：3（检索返回 3 条最相关文档）
   - **Score 阈值**：0.5（相似度低于此值的结果不返回）
5. 在 **「提示词」** 中填写系统提示：

```
你是一个管道腐蚀与完整性管理领域的专家助手。请基于知识库中的 NACE/API/ASME 标准内容回答用户问题。

要求：
1. 回答准确、专业，引用具体标准编号
2. 如果知识库中没有相关信息，明确告知用户
3. 回答使用中文，格式清晰
4. 涉及具体数值时，注明标准和单位
```

6. 选择 **模型**：
   - 推荐使用 `gpt-4o-mini`（性价比高）或 `gpt-4o`
   - **Temperature**：0.3（偏低，保证回答准确性）

7. 点击 **「发布」** 按钮保存配置

---

## 第 5 步：获取 API 凭证

1. 在应用页面左侧，点击 **「访问 API」**
2. 你会看到以下信息：
   - **API 基础 URL**：`https://api.dify.ai/v1`（Dify Cloud 默认）
   - **API 密钥**：以 `app-` 开头的字符串

3. 复制 API 密钥（类似 `app-XXXXXXXXXXXXXXXXXXXXXXXX`）

> ⚠️ API 密钥是敏感信息，不要提交到 GitHub！

---

## 第 6 步：配置 Streamlit Cloud Secrets

1. 打开你的 Streamlit Cloud 应用页面：
   https://pipeline-corrosion-ai.streamlit.app/

2. 点击右下角的 **「⋮」菜单** → **「Settings」**

3. 在 **「Secrets」** 标签页中，粘贴以下内容：

```toml
[dify]
api_url = "https://api.dify.ai/v1"
api_key = "app-你的实际API密钥"
```

4. 将 `app-你的实际API密钥` 替换为第 5 步复制的实际密钥

5. 点击 **「Save」**

6. 应用会自动重启，重启后问答模块将切换到 **Dify API 智能问答模式**

---

## 第 7 步：验证

打开应用后，在「标准问答」Tab 中：

1. 检查顶部状态指示器是否显示 **「🟢 Dify API 智能问答模式」**
2. 尝试点击示例问题，如：
   - "CO2腐蚀的机理和影响因素是什么？"
   - "阴极保护的最小保护电位是多少？"
3. 确认回答是基于标准内容的专业回答（而非配置指引文本）

---

## 常见问题

### Q: 提示 "Dify API 查询失败"
- 检查 API URL 是否正确（应为 `https://api.dify.ai/v1`）
- 检查 API Key 是否完整复制（以 `app-` 开头）
- 检查 Dify 账号是否有可用额度

### Q: 回答内容不相关
- 在 Dify 应用编排中检查知识库是否已正确关联
- 调低 Score 阈值（如改为 0.3）
- 增加 Top K 值（如改为 5）

### Q: 免费额度用完了
- Dify 免费版提供 200 次调用
- 可以升级到付费版（按量付费）
- 或切换到本地向量检索模式（安装 langchain + chromadb）

## 架构说明

```
用户提问 → Streamlit App → rag_engine.py
                                ↓
                        检查 Dify API 配置
                                ↓
                    Dify Cloud API (chat-messages)
                                ↓
                    知识库向量检索 (Top-K)
                                ↓
                    LLM 生成回答 (GPT-4o-mini)
                                ↓
                    返回结构化回答 → 用户界面
```
