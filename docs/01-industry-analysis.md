# 管道完整性管理行业调研报告

> FDE 项目一 | Step 1: 行业速学 | 生成日期: 2026-08-04

## 1. 行业概览

管道是石油天然气工业的"血管"。全球油气管道总里程超过 200 万公里，中国境内油气管道总里程已超过 18 万公里。管道腐蚀是导致管道失效的首要原因，占管道事故总数的 40% 以上。

管道完整性管理（Pipeline Integrity Management, PIM）是一套系统化的管理流程，旨在确保管道在整个生命周期内的安全运行，核心目标是将腐蚀、裂纹、第三方损伤等风险控制在可接受范围内。

## 2. 产业链与关键角色

| 角色 | 职责 | 关注点 |
|------|------|--------|
| **管道运营方** | 日常运营与维护 | 安全、合规、成本控制 |
| **完整性管理工程师** | 风险评估与决策 | 数据分析、标准合规 |
| **内检测（ILI）服务商** | 管道智能检测 | ROSEN、Baker Hughes、NDT Global |
| **腐蚀工程师** | 腐蚀监测与防护 | 腐蚀速率、缓蚀剂、阴极保护 |
| **监管机构** | 安全监督 | PHMSA（美）、国家管网集团（中） |
| **软件平台** | 数据管理与分析 | Irth AIP、Intergraph PRM |

## 3. 核心业务流程

### 3.1 管道完整性管理闭环

```
数据采集 → 风险评估 → 完整性评估 → 维修决策 → 效果验证 → 数据采集（循环）
```

**数据采集阶段**：
- ILI（In-Line Inspection）：管道内检测，使用 MFL（漏磁）、UT（超声）、EMAT 等技术
- CIS（Close-Interval Survey）：密间距阴极保护调查
- DCVG/ACVG：直流/交流电压梯度测量
- 直接评估：ECDA（外腐蚀）、ICDA（内腐蚀）

**风险评估阶段**：
- 基于 ASME B31.8S 的风险矩阵
- 考虑因素：腐蚀速率、管材、压力、人口密度、土壤特性
- 输出：高风险管段优先级排序

**完整性评估阶段**：
- B31G / RSTRENG：腐蚀缺陷适材评估
- 计算剩余强度和爆裂压力
- 判定是否需要维修或降压运行

## 6. 痛点分析

### 痛点 1：标准文档检索效率低（优先级：高）
- **现状**：工程师需要频繁查阅 NACE/API/ASME 标准，但标准文档动辄数百页，检索特定条款耗时 15-30 分钟
- **影响**：降低决策效率，可能导致漏查关键条款
- **AI 解决方案**：RAG 知识库 + 智能问答，3 秒内返回精准条款引用

### 痛点 2：腐蚀风险预测依赖经验（优先级：高）
- **现状**：腐蚀速率预测主要依靠工程师经验和简化模型（de Waard 公式），未充分利用历史数据
- **影响**：预测精度有限，可能导致过度维修或维修不足
- **AI 解决方案**：基于历史 ILI + 环境数据训练 ML 预测模型

### 痛点 3：多源数据整合困难（优先级：中）
- **现状**：ILI 数据、CP 数据、腐蚀监测数据分散在不同系统，格式不统一
- **影响**：完整性评估需要手动整合数据，耗时长
- **AI 解决方案**：自动化数据管道 + 统一数据模型

### 痛点 4：风险评估主观性强（优先级：中）
- **现状**：风险评分依赖工程师个人经验，不同工程师评估结果差异大
- **影响**：资源分配不优化
- **AI 解决方案**：标准化风险评分模型

## 8. 本项目聚焦

基于以上分析，本项目聚焦 **痛点 1 + 痛点 2**：
1. **腐蚀预测模块**：输入管道参数和环境条件 → 预测腐蚀速率和风险等级
2. **标准问答模块**：对 NACE/API/ASME 标准文档进行智能检索和问答

这两个模块共同展示了"AI 在管道完整性管理中的落地能力"，同时利用了我在管道腐蚀方向的专业知识。
