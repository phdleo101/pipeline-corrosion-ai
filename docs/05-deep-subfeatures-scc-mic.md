# 痛点 3（外部 SCC）与痛点 4（MIC）深入子功能规划

> 本文档基于已落地的两个筛查/评分函数，规划"判完之后怎么办"的下一层子功能。
> 现有基础：
> - `scc_susceptibility()`（engineering_models.py）：输出高 pH / 近中性 pH 两类敏感性评分(0–100)与驱动因素（NACE SP0204 SCCDA 思路）。
> - `mic_corrosion()`（environment_models.py）：基于 SRB 数量/营养物/温度/溶解氧输出 MIC 风险等级与速率（仅 SRB 视角）。
>
> 定位：以下为**推荐方案**，部分为可直接实现的子模块；标注"可立即实现"的已给出原型公式。

---

## 一、痛点 3：外部应力腐蚀开裂（SCC）深入子功能

### 现状缺口
现有函数只回答"**这条管对 SCC 敏不敏感**"，没有回答：
1. 敏感了之后，**先挖哪一段**（开挖优先级）；
2. 已有裂纹下，**还能服役多久**（裂纹扩展 + 剩余寿命）；
3. **怎么缓解**（CP/涂层/降压/ILI）；
4. 与**后果**（人口/环境）叠加后的**综合风险排序**。

### 推荐子功能

#### SCC-1 开挖验证决策与优先级排序（可立即实现）
- **输入**：`scc_susceptibility()` 的两类评分 + 是否高后果区(HCA) + ILI 异常指示
- **输出**：开挖优先级（P1 立即 / P2 1年内 / P3 监测）、建议的 **ECDA 四步流程**与每步方法
  - 预评估 → 间接检测（CIS 密间距电位、DCVG 涂层缺陷、Pearson）→ 直接检查（开挖测厚+裂纹 MT/UT）→ 后评估
- **依据**：NACE SP0204（SCCDA）、API RP 1176（SCC 管理）
- **价值**：把"敏感性分数"变成"行动清单"，最贴合工程现场。

#### SCC-2 裂纹扩展速率与剩余寿命（可立即实现，原型已可写）
- **输入**：初始裂纹深度 a₀(mm)、管材屈服强度、操作应力%SMYS、SCC 类型（高pH/近中性）
- **模型**：经验扩展速率（近中性 pH SCC 现场观测约 0.1–1.0 mm/yr；高 pH 更快，可达数 mm/yr）+ 临界裂纹深度 a_c（基于剩余壁厚与流变应力）
  - `a_c = t · σ_f / (σ_f + M·σ_oper)`（M 为 Folias 因子，沿用 B31G 思路）
  - `剩余寿命 = (a_c − a₀) / 扩展速率`
- **依据**：Kiefner & Vieth (Battelle)、API 579 / ASME FFFS-1 裂纹评定
- **价值**：与项目已有的 B31G 剩余强度模块天然衔接，形成"裂纹→寿命"闭环。

#### SCC-3 缓解措施决策树（可立即实现）
- **输出**：按评分给出缓解组合建议
  - CP 优化（近中性 pH SCC 需将管地电位负移到 −0.95 V CSE 以下抑制；高 pH 对 CP 不敏感，靠涂层+降压）
  - 涂层修复（更换剥离旧涂层为 FBE/PE）
  - 降压运行（降低 %SMYS 至 <60%）
  - 裂纹检测型 ILI（EMAT/UT，而非 MFL）
- **依据**：NACE SP0204、PRCI SCC 缓解指南

#### SCC-4 与风险矩阵叠加（复用现有 `risk_matrix()`）
- 将 SCC 敏感性评分映射为"失效概率"维度，与管径/压力/位置（后果）组合，输出综合风险等级与热力图位置。
- **价值**：把孤立的 SCC 筛查并入项目已有的 5×5 风险矩阵，统一管理。

### 优先级建议（痛点3）
| 子功能 | 价值 | 实现难度 | 优先级 |
|--------|------|----------|--------|
| SCC-1 开挖优先级 + ECDA 流程 | 高（直接指导现场） | 低 | **P1** |
| SCC-2 裂纹扩展 + 剩余寿命 | 高（衔接 B31G） | 中 | **P1** |
| SCC-3 缓解决策树 | 中 | 低 | P2 |
| SCC-4 风险矩阵叠加 | 中（复用现有） | 低 | P2 |

## 二、痛点 4：微生物腐蚀（MIC）深入子功能

### 现状缺口
现有函数只覆盖 **SRB 单菌属**风险，且只给"风险等级"。缺口：
1. **其他关键菌属**（APB 产酸菌、IRB 铁氧化菌、SOB 硫氧化菌）未纳入；
2. 没有**杀菌剂方案**（类型/投加/频率/轮换）；
3. 没有**材料升级决策**（何时从碳钢升级到 316/双相/哈氏）；
4. 没有**监测与再评估计划**（挂片/生物膜探针/ILI 周期）。

### 推荐子功能

#### MIC-1 多菌属评估与生物膜热点定位（可立即实现）
- **扩展输入**：除 SRB 外，增加 APB（产酸，pH 下降）、IRB（铁氧化，结瘤）、SOB（硫氧化，局部酸化）
- **输出**：加权多菌属 MIC 指数 + **生物膜/沉积物热点**（低流速段、死管段、水合物/积水段、焊缝盲区）
- **依据**：NACE SP0192（MIC 控制）、NACE TM0194（现场微生物检测）、API RP 38
- **价值**：把"SRB 视角"升级为"群落视角"，更贴近真实 MIC。

#### MIC-2 杀菌剂方案设计（可立即实现，原型已可写）
- **输入**：MIC 风险等级、系统类型（间歇/连续）、水温
- **输出**：杀菌剂类型与投加方案
  - 氧化性（次氯酸钠/二氧化氯）vs 非氧化性（戊二醛、THPS 四羟甲基硫酸磷、DBNPA）
  - 冲击投加 50–200 ppm（依系统容积），连续投加 5–20 ppm
  - **轮换策略**（避免抗药性，如戊二醛 ↔ THPS 季度轮换）
  - 监测指标：SRB 杀灭率（kill ratio ≥ 99%）、挂片失重
- **依据**：NACE SP0192、NACE TM0212（杀菌剂评价）
- **价值**：把"风险高"直接翻译成"加什么药、加多少、怎么轮换"。

#### MIC-3 材料升级决策（复用现有 `pren()`）
- **输入**：MIC 风险等级 + 当前材料 PREN（复用项目 PREN 模块）
- **输出**：升级建议
  - 碳钢高风险 → 316 SS（PREN≈25，有限）或 2205 双相（PREN≈35）或 C-276（PREN N/A，但耐全面腐蚀极佳）
  - 结合工况（温度/氯离子）给出"最低合理可行"材料
- **价值**：与项目 PREN 对比图天然联动，形成"腐蚀环境→材料选型"闭环。

#### MIC-4 监测与再评估计划（可立即实现）
- **输出**：监测方案
  - 在线/离线：腐蚀挂片 + 生物膜探针（NACE SP0192）+ MFL/UT ILI 金属损失
  - 再筛查周期：高风险 6–12 月，中风险 1–2 年
- **依据**：NACE SP0192、API 570（在役检验）

### 优先级建议（痛点4）
| 子功能 | 价值 | 实现难度 | 优先级 |
|--------|------|----------|--------|
| MIC-2 杀菌剂方案设计 | 高（直接可操作） | 低 | **P1** |
| MIC-1 多菌属 + 热点定位 | 高（修正 SRB 偏倚） | 中 | **P1** |
| MIC-3 材料升级决策 | 中（复用 PREN） | 低 | P2 |
| MIC-4 监测再评估计划 | 中 | 低 | P2 |

## 三、建议落地路线

1. **第一批（P1，已落地 ✅）**：SCC-1 + SCC-2、MIC-2 + MIC-1。
   - 这四个子功能已在现有函数输出之上"再算一层"，无需新依赖，且直接产出**可执行建议**。
   - 实现位置：
     - `src/engineering_models.py`：`scc_excavation_priority()`（SCC-1）、`scc_crack_life()`（SCC-2）
     - `src/environment_models.py`：`mic_multi_organism()`（MIC-1）、`mic_biocide_program()`（MIC-2）
     - UI：SCC 子功能在「机理与模型」Tab 的 SCC 子模块内；MIC 子功能在「腐蚀环境分析」Tab 的 MIC 子模块内
2. **第二批（P2，已落地 ✅）**：SCC-3/4、MIC-3/4，做管理闭环与跨模块联动。
   - 实现位置：
     - `src/engineering_models.py`：`scc_mitigation_tree()`（SCC-3 缓解决策树）、`scc_risk_overlay()`（SCC-4 风险叠加，复用 `integrity_tools.risk_matrix()` 的 `prob_idx_override` 参数）

     - `src/integrity_tools.py`：`risk_matrix()` 新增 `prob_idx_override` 参数（向后兼容），支持把非均匀腐蚀概率映射到同一 5×5 矩阵
     - UI：SCC-3/4 在「机理与模型」Tab 的 SCC 子模块内（与筛查共用输入）；MIC-3/4 在「腐蚀环境分析」Tab 的 MIC 子模块内

> 说明：所有新增模型均为**工程筛查/估算**性质，正式设计与合规则以最新版标准与现场检测为准。文档中速率常数取自公开文献与行业经验范围，落地时建议接入用户实测数据标定。

## 五、第三批（P3，已落地 ✅）：SCC 裂纹形貌模拟、MIC 机器学习预测、实测数据标定

### 5.1 SCC 裂纹形貌与扩展蒙特卡洛模拟（SCC 深化）
- 新增 `src/scc_morphology.py`：`simulate_crack_population()`（初始深度与年扩展速率均服从对数正态，蒙特卡洛抽样）+ `build_morphology_figures()`（深度直方图 / 超概率 POD 曲线 / 深度-长度形貌散点-分叉着色）
- 输出 T 年后深度分布、穿壁失效比例（a_c = 壁厚）、POD 曲线，衔接 SCC-2 经验扩展速率区间
- UI：「机理与模型」Tab 新增第 6 子页「🧬 SCC裂纹形貌」

### 5.2 MIC 机器学习预测（MIC 深化，FDE 作品集 AI 工程亮点）
- 新增 `src/mic_ml.py`：
  - `generate_synthetic_dataset()`：按目标风险等级分布（20/35/35/10%）类别条件生成 12 项特征（物理约束：风险越高微生物活性/营养/不利环境越显著）

  - `predict_mic_risk()` / `get_trained_models()`（模块级缓存，进程内仅训练一次）
- 验证指标：分类准确率 ~0.99 / 宏F1 ~0.99；速率回归 R² ~0.94
- **如实标注**：模型基于合成数据训练，正式评估须以现场检测为准（见 Tab8 标定）
- UI：「腐蚀环境分析」Tab 的 MIC 子模块新增「🤖 MIC 机器学习预测」，含风险等级+概率条+特征重要性

### 5.3 实测数据标定（数据驱动闭环）
- 新增 `src/data_calibration.py`：`parse_uploaded_csv()` / `calibrate_with_data()`（自动识别回归/分类，与基线对比）/ `demo_synthetic_df()` / `sample_template_df()`
