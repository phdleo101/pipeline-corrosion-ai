# 方案设计文档

> FDE 项目一 | Step 2-3: 痛点定位与方案设计 | 生成日期: 2026-08-04

## 1. 问题陈述

管道完整性管理工程师在日常工作中有两个高频痛点：

1. **腐蚀风险预测依赖经验判断**：当前腐蚀速率预测主要依靠简化公式（如 de Waard-Milliams）和工程师经验，未充分利用历史检测数据中的模式，导致预测精度有限。
2. **标准文档检索耗时**：工程师需要频繁查阅 NACE MR0175、API 571、ASME B31.8S 等标准文档，每次检索特定条款平均耗时 15-30 分钟，严重影响决策效率。

## 2. 解决方案概述

构建一个 Web 应用，集成两个核心模块：

- **腐蚀预测模块**：基于历史数据训练的 ML 模型，输入管道参数（管材、温度、pH、CO2 分压、流速等）即可预测腐蚀速率和风险等级。
- **标准问答模块**：基于 RAG（检索增强生成）技术，将标准文档导入知识库，支持自然语言问答，3 秒内返回精准条款引用。

## 3. 系统架构

```
用户浏览器
    │
    ▼
Gradio Web 界面（HuggingFace Spaces 部署）
    │
    ├── Tab 1: 腐蚀预测
    │   ├── 输入：管材类型、温度、pH、CO2分压、H2S浓度、流速、氯离子含量
    │   ├── 处理：scikit-learn GradientBoosting 模型推理
    │   └── 输出：腐蚀速率 (mm/a) + 风险等级（低/中/高/严重）
    │
    └── Tab 2: 标准问答
        ├── 输入：自然语言问题
        ├── 处理：LangChain RAG 引擎
        │   ├── 模式A：本地向量检索（ChromaDB + 标准文档）
        │   └── 模式B：Dify Cloud API（已配置知识库）
        └── 输出：答案 + 来源条款引用
```

## 4. 技术选型

| 组件 | 技术选择 | 选择理由 |
|------|---------|---------|
| Web 框架 | Gradio | 免费部署到 HuggingFace Spaces，零运维 |
| 预测模型 | scikit-learn GradientBoostingRegressor | 适合表格数据，可解释性强 |
| RAG 框架 | LangChain | 行业标准，支持多种向量数据库和 LLM |
| 向量数据库 | ChromaDB | 轻量级，本地运行，无需额外服务 |
| LLM | 可配置（通义千问/OpenAI/智谱GLM） | 支持国内外多种大模型 API |
| 部署平台 | HuggingFace Spaces | 免费，支持 Gradio 自动部署 |

## 5. 数据流设计

### 5.1 腐蚀预测数据流

```
模拟腐蚀数据集（CSV）
    │
    ▼
data_processor.py
    ├── 特征编码（管材类型 → 数值）
    ├── 特征缩放（StandardScaler）
    └── 数据分割（80% 训练 / 20% 测试）
    │
    ▼
corrosion_model.py
    ├── 训练 GradientBoostingRegressor
    ├── 评估 R² 和 MAE
    └── 保存模型到 models/corrosion_predictor.pkl
    │
    ▼
app.py 调用模型 → 返回预测结果
```

### 5.2 标准问答数据流

```
标准文档（PDF/TXT）
    │
    ▼
rag_engine.py
    ├── 文档加载与分段（chunk_size=500, overlap=50）
    ├── 向量嵌入（使用 LLM embedding API）
    ├── 存入 ChromaDB 向量数据库
    └── 检索 + LLM 生成答案
    │
    ▼
app.py 调用 RAG 引擎 → 返回答案 + 来源
```

## 6. 输入输出规格

### 6.1 腐蚀预测模块

| 输入参数 | 类型 | 范围 | 说明 |
|---------|------|------|------|
| 管材类型 | 枚举 | 碳钢/不锈钢/合金钢/双相不锈钢 | 影响基础腐蚀速率 |
| 温度 | 数值 | 0-150 °C | 影响化学反应速率 |
| pH 值 | 数值 | 3-10 | 酸碱性影响腐蚀 |
| CO2 分压 | 数值 | 0-10 MPa | 甜腐蚀主要因素 |
| H2S 浓度 | 数值 | 0-1000 ppm | 硫腐蚀因素 |
| 流速 | 数值 | 0-10 m/s | 冲刷腐蚀因素 |
| 氯离子含量 | 数值 | 0-100000 ppm | 点蚀因素 |

| 输出 | 说明 |
|------|------|
| 腐蚀速率 | mm/a（毫米每年） |
| 风险等级 | 低（<0.1）/ 中（0.1-0.5）/ 高（0.5-1.0）/ 严重（>1.0） |
| 建议措施 | 根据风险等级给出防护建议 |

### 6.2 标准问答模块

| 输入 | 示例 |
|------|------|
| 自然语言问题 | "在什么条件下需要使用 NACE MR0175 规定的抗硫材料？" |

| 输出 | 说明 |
|------|------|
| 答案 | 基于标准文档的回答 |
| 来源 | 引用的标准名称和条款编号 |

## 7. 成功指标

| 指标 | 目标值 | 测量方法 |
|------|--------|---------|
| 腐蚀预测 R² | > 0.85 | 测试集评估 |
| 腐蚀预测 MAE | < 0.1 mm/a | 测试集评估 |
| 问答准确率 | > 80% | 人工评估 20 个标准问题 |
| 问答响应时间 | < 5 秒 | 在线计时 |
| Demo 可用性 | 7×24 可访问 | HuggingFace Spaces 在线 |
